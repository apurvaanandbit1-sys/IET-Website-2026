# IET Club Website ⚡

Welcome to the official IET club website — a place for us to build, experiment, learn, and occasionally break things along the way. 🚀 This project is open to all club members who want to contribute, whether you're fixing a tiny bug, designing a new page, adding a cool feature, or just trying something new. **Have fun, experiment, and make it yours.** 💻🔥

## Repository Structure

```text
IET-Website-2026/
├── frontend/          # Frontend client application (React + Vite)
│   ├── public/        # Static assets
│   ├── src/           # Application source code and components
│   ├── index.html     # HTML entry point
│   ├── package.json   # Frontend dependencies and scripts
│   └── ...
├── backend/           # Future backend services
│   └── src/
└── README.md
```

## Getting Started

### Frontend Development

To run the frontend locally:

```bash
cd frontend
npm install
npm run dev
```

### Build & Linting

```bash
cd frontend
npm run lint
npm run lint:css
npm run build
```
